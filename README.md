# hxwl-03 岩土钻孔测斜复核与纠偏台

钻孔测斜测点录入、超限复核与纠偏方案执行的现场工作台

## 技术栈

React + Vite + TypeScript + CSS（localStorage 本机持久化，无后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 业务规则

- 每孔录入**倾角、方位角、测点时间**，深度按**孔口向下**排列
- 倾角 **>3°** 或与上一测点方位变化 **>10°**（圆周最短角差）自动标记，**留待复核**
- 复核**通过后**才能为该测点安排纠偏；驳回须写排查/补测意见
- 纠偏方案必须写**起始深度、纠偏方向、责任班次**
- 方案**执行后锁定**，不可改、不可撤；复测只能**补测另开**并写明原因，原测点失效但记录保留
- 测点超限读数被修订后，原复核按签名自动失效，重新留待复核
- 测点、复核、方案、修订（替代/执行/撤销）四类记录通过 id 互相跳转对应
- 页面顶部**受阻清单**列出：孔号、深度、超限值（未完成复核的测点）
- 全部数据存 localStorage（`hxwl-03-inclination-station-v1`），重开页面仍在；可导出 JSON 台账
