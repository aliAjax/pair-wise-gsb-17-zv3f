# hxwl-03 测斜复核与纠偏台

岩土钻孔现场的测斜录入、超限复核与纠偏方案管理面板。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- **测点登记**：每孔录入深度、倾角、方位角与测点时间，测点按深度自孔口向下排列；补测另开新测点且必填原因，不改写原记录。
- **超限复核**：倾角 > 3° 或较上一测点方位变化 > 10°（含 0/360 环绕）自动留待复核；复核通过后才能编制纠偏方案，退回则维持受阻。
- **纠偏方案**：记录起始深度、纠偏方向与责任班次；执行后经确认即锁定，不可再改。
- **受阻清单**：全工地复核未通过的记录，列出孔号、深度与超限值。
- **修订记录**：录入、补测、复核、方案编制与执行锁定全程留痕。
- **持久化**：状态保存在 localStorage（键 `hxwl-03-survey-console-v1`），重开页面后测点、复核、方案与修订记录仍按 ID 一一对应。

## 说明

- 超限结论在测点录入时计算并固化在记录上，中途补插浅部测点不会改写深部测点的历史判定。
- 可继续扩展 IndexedDB、权限、后端 API 和轨迹图。
